# Security

## Reporting a vulnerability

Don't open a public issue for a security problem. Report it privately through [GitHub's private vulnerability reporting](https://github.com/paulbouwer/hello-kubernetes/security/advisories/new).

Include what you found, how to reproduce it, and the image tag or chart version you used. You will get a reply, and the fix is credited to you unless you ask otherwise.

## Supported versions

Fixes go into the latest 1.x release. Older images and chart versions don't get fixes, so upgrade to the latest release.
