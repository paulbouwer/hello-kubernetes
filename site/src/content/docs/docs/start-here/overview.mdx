hello-kubernetes is a small web app to deploy on a Kubernetes cluster. Its page shows:

- a message, **Hello world!** by default
- the namespace, pod and node that answered
- the container image and its architecture

Refresh the page, and another pod can answer. That makes it a simple way to show how a Service spreads requests across pods and nodes, to test an Ingress or a Gateway, or to check a new cluster.

## What you get

| | |
|---|---|
| **The image** | `paulbouwer/hello-kubernetes` on Docker Hub and `ghcr.io/paulbouwer/hello-kubernetes` on GHCR, for `linux/amd64` and `linux/arm64`. It runs as the non-root user 1000, with signed provenance and an SBOM. |
| **The Helm chart** | `oci://ghcr.io/paulbouwer/charts/hello-kubernetes`. Secure by default, and it can create an Ingress or a Gateway API HTTPRoute for the app. |
| **The release file** | `hello-kubernetes.yaml`: the chart rendered with its defaults, for `kubectl apply` or as a Kustomize base. |
